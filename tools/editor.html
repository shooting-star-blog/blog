התחברות

כדי לפרסם סיפורים באתר צריך טוקן גישה אישי (Personal Access Token) של GitHub.

איך יוצרים טוקן?
  1. נכנסים לחשבון
    GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. לוחצים על "Generate new token"
  3. ממלאים שם לטוקן, תיאור ותאריך תפוגה
  4. תחת Repository access בוחרים "Only select repositories" ובוחרים את המאגר shooting-star-blog/blog בלבד
  5. תחת Permissions בוחרים בהרשאת "Contents" ומגדירים אותה ל-"Read and write"
  6. יוצרים את הטוקן ומעתיקים אותו — הוא יוצג פעם אחת בלבד ולא ניתן לשחזר אותו לאחר מכן אלא רק ליצור אחד חדש
הטוקן יישמר רק בדפדפן שבו מתבצעת ההתחברות. במעבר לדפדפן אחר, יש צורך להזין את הטוקן פעם נוספת. במידה ויפוג תוקף הטוקן, הוא יימחק ויהיה צורך ליצור טוקן חדש
